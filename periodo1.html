Trabalhos do 1º período

O primeiro semestre do Grupo Optimus foi todo em C e C++, rodando no terminal e no Arduino — antes de existir qualquer página web. Como são programas de console, não há link para abrir: cada cartão mostra o que o programa faz e do que ele é feito.

Projeto Mensal

C · 1ª entrega

Quiz multiplayer

Quiz de verdadeiro ou falso para até 5 jogadores — e as perguntas são cadastradas pelo próprio usuário, não ficam fixas no código. Cada jogador responde uma vez só, e no fim o placar sai ordenado por pontuação.

  • Structs
  • Bubble sort
  • Validação de entrada
  • 421 linhas
Ver o código no GitHub → C · 2ª entrega

PDV — Mercadinho

Sistema de ponto de venda inteiro: login com senha, dois níveis de acesso, cadastro de produtos e de usuários, abertura e fechamento de caixa, venda com vários itens e três relatórios. Os dados sobrevivem ao fechar o programa — ficam gravados em arquivos.

  • Structs
  • Arquivos
  • Hash de senha
  • 1.628 linhas

Projeto Integrador de Extensão I

C++ · Arduino

Robô Sumô

Robô autônomo de sumô: quatro sensores infravermelhos leem a borda do ringue para ele não cair, enquanto o ultrassônico procura o oponente. A borda tem prioridade sobre tudo — cair para fora é derrota imediata. Junto vão três programas só para calibrar os motores, os sensores de borda e a distância.

  • Arduino Uno
  • Ponte H L298N
  • 4x sensor IR
  • HC-SR04

Atividades

Doze atividades em ordem de dificuldade — e a ordem não é decorativa: dá para acompanhar o grupo saindo de if/else e chegando em ponteiros e Arduino ao longo do semestre. Todas estão no repositório atividades-periodo1.

01 · C

Avaliação de votos

Urna simplificada: 20 votos entre três candidatos, branco ou nulo, com relatório no fim. Voto inválido não conta e devolve o turno, então a urna sempre fecha com 20 votos válidos.

  • if/else
  • Contadores
 02 · C

Filtrar prioridade

Monitor de processos: lê 10 prioridades, acha maior, menor e a diferença entre elas, e dispara alerta quando alguma passa de 90.

  • Vetor
  • Validação
 03 · C

Verificar duplicados

Compara dois servidores de cinco valores e aponta cada conflito, dizendo a posição nos dois lados — não só que houve conflito.

  • Laço aninhado
  • Dois vetores
 04 · C

String login

Registro e login com senha de no mínimo 8 caracteres. Tentar entrar antes de se registrar é barrado.

  • Strings
  • strcmp
  • fgets
 05 · C

Máquina de moedas

Recebe um valor e devolve a menor quantidade de dinheiro possível. A atividade pedia só as moedas; o grupo estendeu para as cédulas também, de R$ 2 até R$ 200.

  • Algoritmo guloso
  • R$ 200 a R$ 0,05
 06 · C

Quiz v1

Primeira versão do quiz, com menu e pontuação guardada entre uma opção e outra. É o ponto de partida do quiz multiplayer que virou projeto mensal.

  • Menu com estado
 07 · C

Recursividade

Cadastro de clientes e fornecedores em que a listagem não usa laço: a função chama a si mesma com o índice seguinte até chegar ao fim do banco.

  • Recursão
  • Caso base
 08 · C

Struct desafio

Cadastro de até 50 pessoas guardadas numa struct, com busca por sobrenome que devolve todos os que batem, não só o primeiro.

  • struct
  • Busca por campo
 09 · C

Calculadora de matrizes

Soma, subtração, multiplicação e divisão de matrizes 3x3. A multiplicação é a parte boa: não é elemento por elemento, precisa do laço triplo somando linha contra coluna.

  • Matriz 3x3
  • Laço triplo
 10 · C

Ponteiros

Exercício de ponteiros que já é um mini PDV: abrir caixa, cadastrar produtos e vender. É o projeto mensal nascendo dentro de uma atividade de aula — 162 linhas aqui, 1.628 lá.

  • Ponteiros
  • Passagem por referência
 11 · C

Bogosort

Embaralha o vetor, torce para ter ficado ordenado e, se não ficou, embaralha de novo. O algoritmo mais ineficiente que existe — e é justamente aí que dá para enxergar o que complexidade significa.

  • Complexidade
  • 10! = 3.628.800
 12 · C++ · Arduino

Motores e sensores

Os testes que vieram antes do robô: dois motores por ponte H e a primeira leitura de sensor acionando o motor. Foi aqui que a montagem do Integrador I começou a tomar forma.

  • Ponte H
  • PWM
  • Sensor
